## 1. Critical Issues — Verified Fixed

### 1.1 Paper Trading Infinite Error Loop (CRITICAL)
**Status:** ✅ FIXED  
**Root Cause:** Paper-mode DCA bot did not call `connector.connect()`, leaving `exchange` undefined. Additionally, buy orders incorrectly checked `market.base` balance instead of `market.quote` (USDT). The DCA loop interval caught errors but never stopped, causing infinite `Insufficient paper BTC balance` spam.  
**Fix Location:**
- `apps/worker/src/engine/dca-loop.ts` — Added paper `connect({apiKey:"", secret:""})`
- `apps/worker/src/exchange/ccxt-connector.ts` — Paper buy orders now check quote balance; missing currencies initialized to `0`
- `apps/worker/src/engine/dca-loop.ts` — Added `MAX_CONSECUTIVE_ERRORS = 3` auto-stop guard; fatal errors mark bot status `"error"`
- `apps/worker/src/engine/dca-loop.ts` — `shouldTriggerTakeProfit` returns `false` if `vwap <= 0`

---

### 1.2 Prisma Decimal Precision Loss in Fee Applier (CRITICAL)
**Status:** ✅ FIXED  
**Root Cause:** `referral.commissionRate.toNumber()` caused precision loss on `Decimal` fields before multiplying with `fee`.  
**Fix Location:** `apps/worker/src/services/fee-applier.ts:46`  
```ts
// Before (BAD): const commission = fee.mul(referral.commissionRate.toNumber());
// After (GOOD): const commission = fee.mul(referral.commissionRate);
```

## 2. New Findings

### 2.1 Log Server Read Endpoints Unauthenticated (MODERATE)
**Status:** ⚠️ NEW  
**File:** `apps/log-server/src/routes/logs.ts:90` and `:135`  
**Risk:** `GET /logs` and `GET /logs/stream` accept `botId` / `userId` query params without any API key or JWT check. If the log-server port (3012) is ever exposed beyond the internal network, any actor can stream or query bot activity logs.  
**Recommendation:**
1. **Preferred:** Remove the query/stream endpoints from the log server entirely; the API already serves logs to the frontend via `/logs/activity` and `/logs/stream` with full `authMiddleware` + ownership checks.
2. **Alternative:** Add `internalAuth` middleware to `GET /logs`, `GET /logs/stream`, and `GET /logs/stats` so only internal services can read them.

## 6. Remaining Recommendations

1. **Apply internalAuth to log-server reads** (or delete them) — see §2.1.
2. **Add `helmet`-like security headers** to API and log-server (`X-Content-Type-Options`, `X-Frame-Options`, etc.).
3. **Add request-id tracing** across API → Worker → Log Server for easier debugging.
4. **Implement graceful shutdown** in worker (`SIGTERM` handler) to flush pending state to DB before exit.
5. **Add DB connection pooling limits** in Prisma for production load testing.
