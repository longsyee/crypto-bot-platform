Referral Tiers & Admin Panel

Performance-based commission + admin control surface

Referral Tier System
Bronze
5% commission
0–2 active referrals
Silver
12% commission
3–5 active referrals
Gold
20% commission
6–10 active referrals
Platinum
28% commission
11–20 active referrals
KOL
35% commission
21+ active referrals + admin approval
  • "Active referral" = referred user who has deposited tokens at least once.
  • Auto-promote: Bronze→Silver→Gold→Platinum triggers automatically on threshold crossing.
  • KOL gate: Reaching 21+ active referrals sets status to pending_kol. Admin reviews + approves → kol. Commission held at Platinum rate until approved.
  • Demotion: If active referrals drop below tier threshold for 30 days, demote one tier down. Grace period prevents churn abuse.
  • Commission calc: Referrer's % × platform fee (20% of winner PnL). Example: Gold referrer on $100 winner = 20% of $20 fee = $4 to referrer.
Admin Panel — Control Surface
👤 Users
List/search/filter | View balances & transactions | Edit role | Suspend/activate | Reset 2FA | Impersonate (read-only)
🤖 Bots
List all bots across users | Start/stop/pause any bot | Emergency kill switch | View logs & orders | Edit config (with audit trail)
💰 Pricing & Tokens
Adjust token price ($/token) | Change win-fee % (default 20%) | Set referral tier thresholds | Adjust commission rates | View revenue dashboard
🔗 Referrals
View all referral trees | Approve KOL applications | Override commission rate per user | See top earners | Detect self-referral fraud
📊 System Health
Worker queue depth | Redis memory | DB connection pool | Exchange API status (up/down per exchange) | Error rate trends | Active bot count
🚨 Security & Audit
Security events log (failed webhooks, suspicious logins) | Admin action log (who did what, when) | IP allowlist for admin panel | Force password resets

Additional Edge Cases from Admin Lens

  • Admin changes fee % mid-trade: New rate applies to trades filled after the change. In-flight trades use rate at entry time. Stored in bot_orders.fee_rate_at_entry.
  • User dispute (fee too high / trade error): Admin can issue refund via transactions type='refund'. Refund reverses commission ledger entries for that trade too.
  • Exchange maintenance / delisted pair: Worker detects CCXT "Market not found" or "Trading suspended" → pauses all bots on that exchange+symbol. Admin can bulk-resume when exchange recovers.
  • Suspicious referral pattern: Multiple referrals from same IP, same deposit pattern, or circular chain → flagged in admin security panel for review.
  • Token price change: Changing $/token rate affects future deposits only. Existing balances unchanged. Admin must broadcast notice.
  • Bot stuck in "running" but no heartbeat: Worker writes heartbeat timestamp to Redis every 30s. Admin panel shows "healthy / stale / dead" per bot. Stale > 2 min = auto-alert + mark status='unknown'.
